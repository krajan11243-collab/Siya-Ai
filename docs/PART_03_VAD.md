# Part 3 — Silero VAD / Speech Detection

## Implemented
- Silero VAD v5 ONNX streaming wrapper.
- 16 kHz mono input with fixed 512-sample frames.
- 64-sample rolling context and recurrent state.
- Speech probability thresholding.
- Minimum speech duration.
- Minimum silence duration.
- Explicit `SPEECH_START` / `SPEECH_END` events.
- Reset lifecycle between streams.
- PCM adapter that accepts arbitrary AudioRecord callback sizes and emits exact VAD frames.
- Foreground service integration when the local VAD model is installed.
- If the model is absent or fails to initialize, Part 2 microphone capture remains usable instead of crashing.
- No raw PCM logging or persistence.

## Model requirement
The runtime code intentionally expects the actual Silero VAD v5 ONNX binary at:
`filesDir/models/vad/silero_vad_v5.onnx`

The binary is not generated by Kotlin code and is not silently downloaded at runtime, because Siya Ai is designed to remain offline-first. The model must therefore be packaged/imported during the model-installation phase.

Silero v5's official interface uses 512 samples at 16 kHz, with model inputs named `input`, `state`, and `sr`; the implementation follows that streaming contract.

## Verification
Pure state-machine tests cover speech start, silence timeout, reset, threshold/timing behavior. Full ONNX inference and real microphone VAD require the actual model binary plus an Android device/emulator. GitHub Actions was added for JVM/Android unit tests, but the repository currently reports no workflow runs, so this environment cannot honestly claim a green CI build.
